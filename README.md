# 🌟 WishByRaj

**WishByRaj** is a premium emotional greeting card web app that allows anyone to create beautiful wishes in Bengali, Hindi and English.

## ✨ Features

- New Year, Birthday, Love & Motivation modes  
- Smart language detection  
- Deep poetic emotional wishes  
- Animated greeting cards  
- Touch glow & fireworks  
- Mobile friendly & installable  
- Shareable link & WhatsApp sharing  
- Background music
